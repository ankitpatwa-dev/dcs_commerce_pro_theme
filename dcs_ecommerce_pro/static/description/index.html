DCS Commerce Pro - Storefront Core

Shared storefront code used by the DCS Commerce Pro eCommerce theme. It is installed automatically with the theme; you do not need to install it on its own.

  • Header actions (account, cart) shared by the theme's headers.
  • Storefront styling that only applies to websites using the DCS Commerce Pro theme.
